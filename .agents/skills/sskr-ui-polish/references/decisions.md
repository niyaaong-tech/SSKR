현재 지도 배지의 수치 계약은 `tests/browser/map.test.js`와 UI geometry 검사에서 코드와 함께 관리합니다. 값 변경 시 승인된 디자인과 비교해 기대값·관련 배지·두 엔진을 함께 검토합니다. 특정 높이·padding·광학 보정값을 모든 UI의 공통 규칙으로 일반화하지 않습니다.

기능 검사를 통과한 뒤에도 여백·정렬 피드백이 이어졌습니다. 테스트 개수와 캡처 파일 수는 완성도·사용자 승인 지표가 아닙니다. 모델 용량, 브라우저 시작 실패, 오래된 fixture ID와 실제 UX 결함은 원인을 구분해 기록합니다.
