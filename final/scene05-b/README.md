# SSKR Scene 05 B — Extended One-Take Art Pass v2.0

This is the experimental/production-candidate B version of Scene 05.

Scene 05 A v1.8 remains accepted and untouched under `final/scene05/`.

## Revised visual target

> Reality in structure, Art in appearance.

The scene must read as a cinematic aerial landscape of real Korean terrain rather than a GIS render or game board.

Priority:

1. visual art direction and audience satisfaction
2. real terrain credibility
3. dynamic continuous aerial camera work
4. route storytelling

## 60-second one-take

The entire Scene is one continuous virtual-camera shot:

- high-altitude approach
- East Coast descent and Start ignition
- inland Route chase
- crane reveal to national network
- diagonal network flight
- westward sweep
- west Finish descent
- sunset hold
- blue-hour reframe
- festival fireworks

There are no editorial cuts inside the Scene. Camera position, look target, elevation and FOV continuously create new compositions.

## Art systems introduced in v2.0

- procedural animated ocean material instead of a flat-color sea plane
- exponential atmospheric fog that changes through the day
- procedural cloud sprites in multiple depth layers for aerial framing/parallax
- four-stage terrain presentation: dawn / day / sunset / blue-hour-night tint
- real-road-grounded Main Routes with a thin bright core and restrained low-opacity underglow
- reduced decorative road-network emphasis
- dynamic 60-second camera choreography
- lightweight procedural Finish-festival fireworks

## Ending

Personal Recall and Solar Corona are removed from B.

The ending is:

```text
Sunset Finish
→ route graphics settle
→ Blue Hour
→ Finish festival lights
→ ordinary realistic-style fireworks
→ night afterglow
```

Fireworks are a presentation-art metaphor for the finish festival and are not a confirmed operational promise for the real event.
